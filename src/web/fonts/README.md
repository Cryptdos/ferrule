# Fonts

`osifont-lgpl3fe.ttf` is **osifont** 0.1.20230322 by hikikomori82 and contributors, a free font following ISO 3098 technical lettering: https://github.com/hikikomori82/osifont

It is released in three licence variants; Ferrule uses the **GNU LGPL version 3 with font exception** one. The font exception allows embedding the font in documents (such as Ferrule's PDFs) and in software regardless of their licence. The font file is unmodified.

It is the only font on drawings (DESIGN.md §1: no font pickers or styling options). The editor, the print view and PDF export all use it.
